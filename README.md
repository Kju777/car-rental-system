# LZW Car Rental System

A lightweight PHP-based car rental management system
running on Raspberry Pi Zero 2W.

## Features

### User
- Browse available cars
- Create rental bookings
- View rental history

### Admin
- Manage cars
- Manage users
- Manage reservations

## Technologies

- PHP
- MariaDB
- Apache2
- Raspberry Pi Zero 2W
- DietPi
- Git
